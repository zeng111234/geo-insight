## 总结论

**三个平台全部判定「可行」：个人实名 + 在线充值即可开通官方 API，无一处强制企业主体、对公账户或最低充值。**
roadmap 风险登记第一条「平台 API 拿不到资质」不触发，**H3 走自动采集路线成立**，人工采集流程（H2-2 闭环）保留为降级预案。

| 维度 | 豆包（火山方舟） | DeepSeek | Kimi（Moonshot） |
|---|---|---|---|
| 个人准入 | ✅ 手机号注册 + 扫脸/银行卡个人实名 | ✅ 个人实名，**个人/企业权益无差异** | ✅ 个人实名 + 微信/支付宝充值 |
| 主力模型 | doubao-seed-2-1-pro / lite | deepseek-flash / deepseek-v4-pro | kimi-k3.1-pro（旧 deepseek-chat、kimi-k2 已退役/下线） |
| 月成本（我方量级*） | **¥33（lite 低优）~ ¥720（pro 常规）** | **¥97.5（flash 错峰）~ ¥675（pro 高峰）** | **¥977（k3.1-pro Batch）~ ¥2,400（k3 实时）** |
| 限流 | RPM 500 / TPM 1M（pro 默认，模型级） | 仅并发：flash 2500 / pro 500（账号级） | 充值分级：¥50 → RPM 100、TPD 不限 |
| 输出归用户 | ✅ 不主张所有权 | ✅ 明确归属，允许广泛使用 | ✅ 明确归属，「自行存储」写进协议 |
| 存储 180 天原文 | ✅ 无禁止条款 | ✅ 无禁止条款 | ✅ 协议明说「自行对客户数据进行存储」 |
| 默认用于训练 | **默认不训练**（勿入协作奖励计划） | 可能用于，**有退出开关** | 个人默认授权优化，**API 无书面退出**（企业默认不训练） |
| 自动化批量调用 | 官方明示支持（低优档适用场景） | 官方按高并发设计 | 无禁止条款，限速按充值分级 |

**起步选型建议**（H3-2 第一个 adapter 的输入）：
- **首选 DeepSeek（deepseek-flash）**——个人/企业权益无差异、并发 2500 且免费工单扩容、错峰半价后约 ¥100/月、输出权利归属条款最干净；错峰时段（工作日 9-12/14-18 之外）跑每日采集正合适。
- **成本敏感备选：豆包 doubao-seed-2.1-lite 低优档（约 ¥33/月）**——官方把「大批量刷数/评测/离线打标」列为低优 flex 的适用场景，就是为这种任务设计的。
- **Kimi 最贵（约 ¥1,000+/月）但无准入瓶颈**；若在意「个人账户输入输出默认授权用于模型优化且无 opt-out」，可邮件 support@moonshot.cn 洽询或评估企业认证（企业数据默认不训练）。

## 一、豆包（火山引擎 / 火山方舟 Ark）

### 准入条件
- 注册仅 +86 手机号，个人可直接注册（[账号注册流程](https://docs.volcengine.com/docs/account-related/account-registration-process)）。
- 实名必做（中国法规）：个人扫脸/银行卡即时完成；海外个人不支持个人实名（[实名认证说明](https://docs.volcengine.com/docs/account-related/basic-introduction)）。
- 开通模型服务：控制台「开通管理」对目标模型点开通即可，**无企业资质、对公账户、最低充值要求**（[开通管理](https://docs.volcengine.com/docs/ark/activation-management)）。充值支持支付宝/微信/个人网银（[充值指引](https://docs.volcengine.com/docs/billing-center/top-up)）。
- 个人 vs 企业差异：发票（个人仅普票）与关联账号数；**未见**方舟模型范围对个人设限的条款（完整差异清单未能核实，以控制台为准）。

### 价格（元/百万 token，[模型服务价格](https://docs.volcengine.com/docs/82379/1544106)，2026-11-24 更新）
| 模型/档位 | 输入 | 缓存命中 | 输出 |
|---|---|---|---|
| seed-2.1-pro 常规 | 6.00 | 1.20 | 30.00 |
| seed-2.1-pro 低优 flex | 3.00 | 1.20 | 15.00 |
| seed-2.1-lite 常规 | 0.80 | 0.16 | 2.70 |
| seed-2.1-lite 低优 flex | 0.40 | 0.16 | 1.35 |

- 低优 flex（`service_tier=flex`）约为常规 5 折，不承诺 SLA，官方明示适用「大批量刷数/评测/闲时成本敏感任务」；批量推理同为 5 折。
- 新用户有免费推理额度（文档口径「50w token」量级，确切数值以控制台为准——未能核实）。
- 我方月成本：lite 低优 ≈ ¥33 / lite 常规 ≈ ¥67 / pro 低优 ≈ ¥360 / pro 常规 ≈ ¥720。

### 限流（[模型列表](https://docs.volcengine.com/docs/82379/1330310)）
- 模型级默认：pro/turbo RPM 500、TPM 1M；lite RPM 30000、TPM 5M。提额走工单或付费 TPM 保障包；按实名类型自动分级未公开。
- 我方约 8-9 RPM、1.7 万 TPM/分钟——默认配额远超所需。

### 存储与训练条款（[豆包模型服务协议](https://docs.volcengine.com/docs/ark/doubao-model-service-agreement) 2026-09-17 版）
- **默认不训练**（第 4.1 条）：「不使用您提交给服务或使用服务输出的内容训练、重新训练或改进基础模型」；例外只有两个：加入协作奖励计划、Coding/Agent Plan 个人版包月套餐的数据授权——**这两个都不要碰**。
- 输出所有权归用户（第 5.3 条）；存储、指标计算、分析不受限；但不得把输出拿去训练/微调其他模型（第 2.4 条）。
- 平台条款（3.7.7）：「未经您的单独同意，火山引擎不会存储和使用您的数据来训练或优化模型」。

### 注意事项
- 不加入协作奖励计划、不用包月套餐做采集；报告保持非公开（对外发布需按 AIGC 标识办法加标识）。

## 二、DeepSeek（深度求索）

### 准入条件
- 个人可注册使用 API；协议明确适用「个人或企业开发者」；**个人/企业认证权益与功能无差异**（[官方 FAQ](https://static.deepseek.com/faq/index.html?lang=zh#/category/4)）。
- 实名：个人实名（姓名+证件号）即可，支付宝/微信在线充值；对公汇款仅企业可用（我们用不上）。
- 模型变化（重要）：`deepseek-chat` / `deepseek-reasoner` 已于 **2026-07-24 退役**，现役 `deepseek-flash`（轻量）与 `deepseek-v4-pro`（旗舰）（[发布公告](https://api-docs.deepseek.com/news/news260424/)）。

### 价格（元/百万 token，[官方定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)）
| 模型 | 输入(未命中) | 输入(命中) | 输出 |
|---|---|---|---|
| flash 空闲/高峰 | 1 / 2 | 0.02 / 0.04 | 4 / 8 |
| v4-pro 空闲/高峰 | 4.5 / 9 | 0.15 / 0.30 | 13.5 / 27 |

- **错峰半价**：工作日 9-12、14-18 为高峰，其余时段（含周末、凌晨）半价——每日采集任务排错峰即省一半。
- 我方月成本：flash 全错峰 ≈ ¥97.5 / 全高峰 ≈ ¥195；v4-pro ≈ ¥337.5-675。
- ⚠️ `deepseek-flash` **默认开启思考模式**且思考 token 计入输出计费——采集必须显式关闭（`{"thinking": {"type": "disabled"}}`）或按 2-4 倍输出预算预留（[思考模式指南](https://api-docs.deepseek.com/guides/thinking_mode/)）。

### 限流（[限速与隔离](https://api-docs.deepseek.com/zh-cn/quick_start/rate_limit)）
- 只公布并发：flash 2500 / v4-pro 500（账号级，与 API Key 无关）；RPM/TPM 未公布；更高需求提交**免费扩容工单**。
- 我方峰值并发 1-2，毫无压力。

### 存储与训练条款（[开放平台服务协议](https://cdn.deepseek.com/policies/zh-CN/deepseek-open-platform-terms-of-service.html) 2026-04-29 生效）
- 输出权利归用户，明示可用于「个人使用、学术研究、衍生产品开发」等广泛场景（4.2 条）——存 180 天原文 + 算指标在许可范围内。
- 训练：可能用于「经去标识化处理后」的模型优化，**可退出**：关闭「数据用于优化体验」开关（App 内路径明确；网页控制台入口注册后确认——未能直接核实，未登录）。
- 对外发布输出时须标注 AI 生成（用户协议 3.1）；内部报告与客户交付物无平台审批要求。

### 注意事项
- 采集程序处理两类失败：429（并发超限退避）与 `finish_reason=content_filter`（内容拦截返回空内容，[安全指南](https://api-docs.deepseek.com/guides/safety/)）——正好归入 H3-4 的失败分类（风控/拒答）。
- 新用户赠送额度与充值下限未能核实。

## 三、Kimi（Moonshot 月之暗面）

### 准入条件
- 个人可注册开通 API，不强制企业资质（[服务协议](https://platform.kimi.com/docs/agreement/modeluse.md) 2026-08-31 版）。
- 实名是充值前置（不实名不能充值）；在线充值微信/支付宝。
- 限速按**累计现金充值**分级，个人/企业一视同仁；企业独享：Admin API、ZDR、SLA、IP 白名单（[充值与限速](https://platform.kimi.com/docs/pricing/limits)）。
- 域名迁移：platform.moonshot.cn 已 301 至 platform.kimi.com；旧模型（kimi-latest、moonshot-v1、kimi-k2 系列）已下线或 2026-12 底退役，新账号只能用 K3/K3.1。

### 价格（元/百万 token，[官方定价](https://platform.kimi.com/docs/pricing/chat)）
| 模型 | 输入 | 输出 | 缓存命中 |
|---|---|---|---|
| kimi-k3.1-pro | 13.00 | 68.00 | 1.30 |
| kimi-k3 | 20.00 | 100.00 | 2.00 |

- Batch API 6 折（适合每日低实时性采集）；新用户认证后送 15 元代金券（不计入限速充值）。
- 我方月成本：k3.1-pro 实时 ≈ ¥1,628 / Batch ≈ ¥977；k3 ≈ ¥2,400 / Batch ≈ ¥1,440。

### 限流（[充值与限速](https://platform.kimi.com/docs/pricing/limits)）
- 按累计充值分级：Tier0（¥0）并发 1 / RPM 3 / TPD 150 万；**Tier1（累计 ¥50）RPM 100、TPD 不限**——我方量级数分钟跑完，无瓶颈。
- ⚠️ **TPD 按「请求 token + `max_completion_tokens` 参数」计**，而 K3 系列该参数默认 131072——不显式设小，Tier0 约 11 个请求就耗尽日额度。采集脚本必须显式 `max_completion_tokens≈2048`。
- 风控限速一旦触发「无法解除」——保持平稳调用节奏。

### 存储与训练条款（[服务协议](https://platform.kimi.com/docs/agreement/modeluse.md)）
- **允许且要求自行存储**（第五.5 条）：「您应根据自身需求自行对客户数据进行存储」——180 天留存无障碍。
- 输出知识产权归用户（第六.2 条）。
- **个人账户：输入输出默认授权用于「模型服务优化」，协议无 opt-out 条款**（第六.3 条）——介意的话邮件 support@moonshot.cn 洽询或评估企业认证（企业默认不训练，[ZDR 说明](https://platform.kimi.com/docs/guide/zero-data-retention)）。
- 无「禁止再分发输出」一般性禁令；对外发布须遵守 AIGC 标识规定。

## 采集程序的工程注意事项（H3-2 adapter 实现输入）

1. **Kimi**：显式设小 `max_completion_tokens`（TPD 计费口径包含它）。
2. **DeepSeek**：显式关闭 flash 的思考模式（思考 token 按输出计费）；任务排错峰时段半价；处理 `content_filter` 空回复。
3. **豆包**：低优 flex 档（`service_tier=flex`）为我方场景的官方推荐档；高峰期可能排队 20 分钟，调度器要容忍。
4. 三平台都是 OpenAI 兼容接口——adapter 可共用一套 OpenAI 风格客户端，只换 base_url + key + 模型名 + 平台特定参数。
5. 失败分类（H3-4）对接：429 → 超时/限流；`content_filter` → 拒答/风控；Kimi 风控限速 → 风控。
6. 报告与页面引用模型原文时保持「内部/客户交付」边界；如对外公开发布，加 AIGC 生成标识（三平台条款共同要求）。

## 路线分叉建议（供 T002 决策）

- **主线：自动采集。** 三平台准入均无企业门槛，存储均无障碍，成本量级 ¥100-2,000/月（按选型），默认限流全部覆盖我方量级。
- 人工流程（H2-2 缺样本清单闭环）**保留不拆**：作为平台风控/账号异常时的降级路径（Kimi 风控限速不可解除这类尾部风险仍存在）。
- H3-2 首个 adapter 选 DeepSeek（理由见总结论）；H3-1 关闭，风险登记第一条结案。
