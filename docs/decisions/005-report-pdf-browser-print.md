# 决策 005：报告 PDF 由浏览器打印生成，不做服务端渲染

**日期**：2026-11-11（2026-11-12 追认补录）
**状态**：已生效
**触发**：`/speckit-analyze` 发现 U2/U3 一类问题——契约里写了 `POST /reports/{id}/export`，却没有任何实现；同时 `FR-030 / SC-005` 要求「导出」与「页面一致率 100%」。

## 背景与约束

- 本机装不了 `reportlab` / `weasyprint` / `playwright`（PyPI 不可达），服务端 PDF 渲染不可行。
- 服务端另起 headless 浏览器会引入第二个进程，与决策 002「单进程」冲突。
- 面试演示只需要能当场导出一份与页面一致的 PDF。

## 备选方案

| 方案 | 优点 | 代价 | 结论 |
|---|---|---|---|
| A. 服务端 PDF 渲染（reportlab / weasyprint） | 可后台批量生成、可定时发送 | 需安装依赖；中文 fonts 处理、分页与表格都要单独实现；容易与页面样式漂移 | **放弃** |
| B. 浏览器打印（`@media print` + `window.print()`） | 零依赖；所见即所得；天然与页面同源数据；中文字体由系统提供 | 需用户点一次「打印 / 另存为 PDF」；不能后台批量 | **采用** |
| C. headless Chrome 截图/打印 | 可后台 | 需要额外二进制与进程；本机不可得 | **放弃** |

## 决定

- 报告详情页 `report.html` 提供「打印 / 导出 PDF」按钮，调用 `window.print()`；配套 `@media print` 隐藏导航、按钮与操作区。
- 页面渲染的字段与打印输出的字段来自**同一个** `GET /v1/reports/{id}`，因此不存在两套模板漂移；导出即快照。
- `contracts/openapi.yaml` 移除未实现的 `POST /reports/{id}/export`，避免契约撒谎；契约说明中明确 PDF 走浏览器打印。
- `SC-005` 的验收方式改为「逐字段比对 6 个指标值 + 周期 + 样本量 + 口径版本 + 生成时间 + 不可比原因」，**不比对字体与布局**。

## 关于 FR-031「重试不得重复扣额度」

首版没有积分与额度系统（决策 003 已取消），因此不存在「扣额度」动作。为了防止同一周期重复生成造成重复报告，`POST /trackers/{id}/reports` 对相同 `(tracker, 起止日期, 口径版本)` 返回已存在的报告并标注复用，不新增记录；报告快照 `payload` 一旦写入不再改写，`payload_hash` 用于校验。

## 代价与限制

- 不能无人值守批量导出，也不能定时邮件发送；这是产品化阶段的事。
- 不同浏览器的打印分页略有差异，故 SC-005 明确不比对布局。
- 打印对话框里选择「另存为 PDF」属于人工一步，面试演示需提前说明。

## 回退 / 升级条件

需要后台批量生成、定时分发或精确分页页码时，再评估服务端渲染；届时保留 `GET /v1/reports/{id}` 不变，只新增导出端点（宪法原则 V）。
