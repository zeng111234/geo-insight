# 003 · 内容工作室不复刻参考产品：不做 AI 成稿，不做积分

**状态**：已采纳（用户决定：先砍演示态）
**日期**：2026-11-11
**影响范围**：`frontend/static/studio.html`、002 的 FR-004 / Out of Scope / tasks T013、T021

## 背景

用户提供了一段「GEO Insight 创作工作台」的演示视频截图，明确说明**只作灵感，不要 1:1 复刻**。
参考产品的形态是：三栏（创作要求 / 正文编辑 / 事实与证据）+ Credits 计费 + 「AI 生成草稿 5 积分」+
「生成视频脚本 5 积分」+ 7 个发布平台。

## 判断

复刻这套形态会同时继承它的三个问题：

1. **计费鼓励产量，而不是效果**。按次扣积分的模式，产品价值被定义成「生成了多少字」，
   而客户真正买的是「被 AI 推荐」。产量与提及率没有正相关，做积分体系是纯成本：
   要账本、扣减、退款、并发安全，还要防止刷单。
2. **把合规风险最高的动作放在最显眼位置**。律师行业不得对结果作承诺，
   AI 批量成稿是最容易产出违规表述的环节。把它做成主按钮，等于把风险前移到客户手上。
3. **平台数量是假繁荣**。7 平台意味着 7 套登录态、7 套风控、7 套排版适配；
   真实登录与自动发帖是最脆弱的环节（验证码、封号、条款限制），
   一旦押上去，交付会被单点拖垮。

## 决策

1. **移除 Credits 与全部 AI 成稿入口**（含「AI 助手」按钮）。页面上不再出现积分、
   不出现「AI 生成草稿/视频脚本」按钮。
2. 编辑器定位改为：**人工成稿，系统只做事实核对与合规提示**。页面顶部明示这句话。
3. AI 的能力边界收窄为「基于诊断回答的提纲建议」，且**本期不实现**；将来若做，
   必须重新立规（记入宪法原则 II 的展示态规则）。
4. 侧边栏只保留真实存在的页面，删掉 6 个 `#` 死链（优化机会、优化任务、报告中心、
   品牌资产、探索工具、行业信息分布）。宁可少，也不做「看起来完整」的假象。

## 与参考产品的差异（保留的部分）

| 参考做法 | 我们的做法 | 原因 |
|---|---|---|
| 三栏同屏 | **保留** | 写作时不用跳页，证据就在旁边，这个结构是对的 |
| 创作要求结构化 | **保留并强化** | 把优化目标与验收条件写进文章，才能和指标闭环挂钩 |
| 事实与证据侧栏 | **保留**，待核实排前 | 先补证据再审核，顺序正确 |
| Credits + 5 积分/次 | **删除** | 与「被引用」的价值主张冲突，且是纯成本 |
| AI 成稿主按钮 | **删除** | 合规风险最高，且会把产品做成内容工厂 |
| 7 平台铺量 | **本期不做**，收敛到少而准 | 登录与风控不可控，铺量对律所客户是负收益 |

## 代价

- 页面看起来没那么「满」：少了积分、AI 按钮、6 个导航项。这是刻意的，
  用留白换「每一块都是真的」。
- 若将来客户明确要求「批量成稿」，需要重新评估合规与计费，不是加个按钮就能补回来。

## 验证方式

- 页面级负向断言进冒烟测试：`/studio` 返回的 HTML 中不得出现 `Credits`、
  `5 积分`、`AI 生成草稿`。这三条在改动前必然失败，改完通过。
- 规格与任务同步：FR-004 改为「MUST NOT 提供」，T021 标记为取消而不是待办。
